# Est · Tlahuizcalpan · sources et modeles

Base documentaire du chantier « identite de l'Est » (page Services, dore),
constituee le 06/09/2026, meme rigueur que le Sud et l'Ouest : chaque
element visuel doit pouvoir citer sa source ; les licences sont nommees.
Idee forte retenue dans les fiches de scene (05/09) : LES DARDS DE L'AUBE.

## Les noms

- tlahuizcalpan = « a l'aube, au point du jour » (Molina 1571 : « al alua,
  o en amaneciendo » ; Olmos 1547). Tlahuizcalpantecuhtli = « le seigneur
  de la maison de l'aube », Venus etoile du MATIN.
  https://nahuatl.wired-humanities.org/content/tlahuizcalpan
- L'Est dans les livres divinatoires (Codex Fejervary-Mayer, page 1) :
  Tlapallan / Tlapcopa, couleur ROUGE, dieu Tonatiuh, signes des jours
  cipactli, coatl, atl, acatl, ollin. Notre DORE est une licence (l'or =
  teocuitlatl, le metal du soleil), a dire dans le Codex comme le cendre
  de l'Ouest.
  https://www.mexicolore.co.uk/aztecs/ask-us/what-was-the-symbolism-of-the-four-directions

## Le mythe : le soleil cree a Teotihuacan (Sahagun, livre VII, ch. 2)

- Les dieux reunis a Teotihuacan ; Nanahuatzin, le Pustuleux, saute dans le
  brasier ; Tecciztecatl le suit et devient la lune ; un dieu lui jette un
  lapin au visage pour l'eteindre.
- Le soleil se leve mais NE BOUGE PAS : il brule tout. Les dieux se
  sacrifient et Ehecatl, le vent, le pousse enfin sur sa route.
  https://en.wikipedia.org/wiki/Nanahuatzin (cite Sahagun)
- Details a VERIFIER sur le texte (Getty, livre VII, certificat en erreur
  le 06/09 ; relire https://florentinecodex.getty.edu/book/7) : les dieux
  s'agenouillent et regardent dans toutes les directions pour deviner ou
  il sortira ; ceux qui regardent vers l'EST (Quetzalcoatl-Ehecatl, Totec,
  les Mimixcoa, quatre femmes) ont raison ; le soleil sort ROUGE, VACILLANT
  d'un cote a l'autre, impossible a regarder en face. Ces trois details
  sont ceux que la scene voudrait montrer : ne les affirmer dans le Codex
  qu'apres relecture.
- Livre VII sur la Library of Congress (fac-simile) :
  https://www.loc.gov/item/2021667852/

## Les dards de l'aube (Leyenda de los Soles, Codex Chimalpopoca)

- Tlahuizcalpantecuhtli, furieux que le soleil ne bouge pas, lui tire des
  dards au propulseur (atlatl) ; il le manque ; le soleil lui renvoie un
  dard et le change en Itztlacoliuhqui, « lame d'obsidienne courbe », dieu
  du froid et du gel.
  https://en.wikipedia.org/wiki/Tl%C4%81huizcalpantecuhtli
  https://en.wikipedia.org/wiki/Itztlacoliuhqui (Andrews 2003 : « tout
  s'est courbe sous le froid », le tueur de plantes ; il tient un BALAI de
  paille, tlachpanoni, qui nettoie le chemin pour la vie nouvelle).
- Les presages de Venus (Anales de Cuauhtitlan) : selon le signe du jour ou
  elle reparait a l'aube, ses dards frappent les vieillards (1 Cipactli),
  les petits enfants (1 Ocelotl, 1 Mazatl, 1 Xochitl), les seigneurs
  (1 Acatl), tout le monde (1 Miquiztli), les jeunes (1 Ollin), la pluie
  (1 Quiahuitl : secheresse), l'eau (1 Atl : secheresse). On calfeutrait
  portes et fenetres. Attestation : Wikipedia ci-dessus, d'apres Bierhorst,
  History and Mythology of the Aztecs (deja dans les sources du Codex).
- Etude de reference : Mathiowetz, Schaafsma, Coltman, Taube, « The Darts
  of Dawn: The Tlahuizcalpantecuhtli Venus Complex », Journal of the
  Southwest, 2015.
  https://www.academia.edu/2368653/

## Tonatiuh

- Regne sur l'Est ; peint en ROUGE, coiffe de plumes d'aigle, bouclier /
  disque solaire ; l'aigle = son voyage quotidien (l'aigle qui monte,
  l'aigle qui descend). Les guerriers morts et les femmes mortes en
  couches l'accompagnent (cf Sud et Ouest).
  https://en.wikipedia.org/wiki/T%C5%8Dnatiuh

## Le vrai ciel

- Venus etoile du MATIN : conjonction inferieure ~23-24/10/2026, puis
  elongation ouest croissante, maximum ~47 deg debut janvier 2027
  (src/lib/venus.ts, deja verifie). Miroir exact de la regle de l'Ouest :
  a l'Est, l'evenement des dards serait sur quand Venus est reellement du
  matin, sinon une fois sur trois.
- Le soleil se leve a l'est vrai a l'equinoxe ; heure de Mexico par
  src/lib/solar.ts si on veut l'aube reelle en contemplation.

## Ce qui est atteste / ce qui serait licence

- Atteste : le soleil cree a Teotihuacan, immobile puis pousse par le vent ;
  les dards de Venus contre le soleil, le dard en retour, la metamorphose
  en gel ; Venus du matin qui blesse selon le jour ; l'Est rouge de Tonatiuh.
- Licence : la couleur doree, la forme des dards a l'ecran, le gel qui fond
  sur l'herbe au lever, l'aigle s'il est montre, le vacillement du soleil
  tant que le livre VII n'est pas relu.
- Jamais : recopier une figure des codex (Borgia 53) ; le nahualli reste
  cache.

## Complement 07/09 : la lance du soleil

- La Leyenda de los Soles parle de dards au propulseur (atlatl). A l'ecran,
  un dard a empennage se lit comme une fleche (retour Sylvain) : la lance
  du soleil est un TEPOZTOPILLI, la lance de guerre mexica : longue hampe,
  large tete plate en feuille bordee de lames d'obsidienne enchassees
  (Codex Mendoza, folios des guerriers ; Hassig, Aztec Warfare, 1988).
  Licence dite dans le code. https://en.wikipedia.org/wiki/Tepoztopilli
- 07/09 : la lance est MODELISEE dans Blender par script
  (tools/blender/tepoztopilli.py -> public/models/tepoztopilli.glb, 2300
  triangles) : hampe conique, tete en feuille lenticulaire a arete
  centrale, 8 lames d'obsidienne par bord en prismes barbeles, virole,
  ligatures, 7 plumes sous la tete. Materiaux nommes (Wood, Head, Obsidian,
  Binding, Feather) ; les matieres de feu sont posees sur le site.
